SAFAR SHERZAD — ڕێنمایی دامەزراندن

ئەم پڕۆژەیە پێکهاتووە لە:
- index.html: پەڕەی فرۆشگا
- style.css: دیزاینی وێبسایت
- app.js: کاڵاکان، چوونەژوورەوە و داشبۆردی Owner
- schema.sql: خشتەی داتابەیس و ڕێساکانی پاراستن

گرنگ: فایلەکان ئامادەن، بەڵام وێبسایتەکە هێشتا لە ئینتەرنێت بڵاو نەکراوەتەوە و Supabase پێویستی بە ڕێکخستن هەیە.

هەنگاو ١ — دروستکردنی داتابەیس
1. بچۆ بۆ https://supabase.com و پڕۆژەیەکی نوێ دروست بکە.
2. لە SQL Editor، ناوەڕۆکی schema.sql کۆپی بکە و Run بکە.
3. لە Project Settings > API، Project URL و anon/public key وەربگرە.
4. لە app.js شوێنی PASTE_YOUR_SUPABASE_PROJECT_URL_HERE و PASTE_YOUR_SUPABASE_ANON_KEY_HERE بە نرخە ڕاستەقینەکان بگۆڕە. تەنها anon/public key بەکاربهێنە؛ service_role key مەخە ناو وێبسایت.

هەنگاو ٢ — دروستکردنی Owner
1. لە Supabase > Authentication، هەژمارێک بۆ safarsherzad425@gmail.com دروست بکە.
2. ئیمەیڵەکە پشتڕاست بکەوە و وشەی نهێنییەکی بەهێز دابنێ.
3. تەنها ئەم ئیمەیڵە لە ڕێساکانی schema.sql مافی بەڕێوەبردنی کاڵای هەیە. هیچ وشەی نهێنییەک لە کۆدەکەدا مەنووسە.

هەنگاو ٣ — بڵاوکردنەوە لە GitHub Pages
1. لە GitHub repository ـەکەت، ئەم چوار فایلە باربکە.
2. لە Settings > Pages، branch ـی main و folder ـی /(root) هەڵبژێرە و Save بکە.
3. چەند خولەک چاوەڕێ بکە، پاشان لینکی GitHub Pages بکەرەوە.

هەنگاو ٤ — تاقیکردنەوە
1. وێبسایتەکە بکەرەوە و لە Owner login بچۆ ژوورەوە.
2. کاڵایەک زیاد بکە و پەڕەی کڕیاران نوێ بکەرەوە.
3. بە browser یان مۆبایلێکی تر تاقی بکەرەوە کە کڕیاران کاڵای بڵاوکراوە دەبینن.

تێبینیی گرنگ:
- تا Supabase URL و anon key دابنەیت، وێبسایتەکە تەنها دیمۆیە و کاڵاکانی نموونە پیشان دەدات.
- ئەم وێبسایتە پەڕەی داواکردن بە ئیمەیڵ دەکات؛ سیستەمی پارەدان یان داواکارییەکانی ناو داتابەیس لەم وەشانەدا نییە.
- بۆ پاراستنی زیادە، لە Supabase هەژماری Owner تەنها بۆ ئیمەیڵی خۆت بهێڵەوە و دوو-هەنگاوی پاراستن چالاک بکە ئەگەر بەردەست بوو.
